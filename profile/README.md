# FutraDay

**Practical AI, SaaS and automation products built to solve real business problems.**

FutraDay is a Melbourne-based product studio building useful software from idea through working release, with a focus on AI-assisted workflows, automation and practical digital products.

## What we build

- AI-powered software and agents
- SaaS products and internal tools
- Business process automation
- Voice, content and workflow systems
- Experimental products with a path to real-world use

## How we build

We focus on practical releases, reliable systems and measurable usefulness rather than software that never reaches users.
