# Security

FutraDay treats security issues as private reports until a fix or mitigation is available.

## Reporting a vulnerability

Please email **hello@futraday.com.au** with:

- the affected repository, product, or URL
- the issue and potential impact
- clear reproduction steps or a proof of concept
- any relevant logs, screenshots, or version details

Do **not** open a public GitHub issue for an unpatched vulnerability or include secrets, credentials, personal data, or customer data in a report.

We will review the report, investigate the affected component, and coordinate remediation as appropriate. Repository-specific security instructions override this organization-wide policy when present.
